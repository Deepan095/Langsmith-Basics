# LangChain and LangSmith Basics

A beginner LangChain project that accepts a user question, sends it to an OpenAI model, and displays the AI-generated answer.

## Technologies Used

- Python
- LangChain
- OpenAI
- LangSmith

## Features

- User input
- Prompt Template
- ChatOpenAI
- Output Parser
- LangSmith tracing

## Run

```bash
python langsmith_basics.py
```
